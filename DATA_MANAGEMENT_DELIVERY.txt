DEPLOYMENT INSTRUCTIONS
================================================================================

1. Execute database migration:
   $ psql universities_voice < migrations/004_data_management_settings.sql

2. Set environment variables:
   - DB_USER, DB_PASSWORD, DB_HOST, DB_PORT, DB_NAME
   - ENCRYPTION_KEY (generate with encryption-utils)
   - BACKUP_STORAGE_PATH

3. Install dependencies:
   $ npm install

4. Build Next.js:
   $ npm run build

5. Start application:
   $ npm start

6. Verify endpoints:
   $ curl -H "Authorization: Bearer <token>" \
     http://localhost:3000/api/settings?universityId=<id>

7. Initialize settings:
   - Create admin settings for each university
   - Configure backup schedules
   - Set up email templates
   - Create notification preferences
