# Universities-Voice — Voice Guide

## Tone
Informative, direct, institutional-friendly. We report; we don't hype. The voice
is that of a reliable campus bulletin — clear, neutral, and respectful of all
18 universities equally.

## Person & address
- Third person for news ("The university announced…").
- Second person for UI copy and CTAs ("Browse the latest news", "Sign up").
- Never first-person singular. "We" only in the About page.

## Bilingual rules
- Arabic is the primary language; English is a parallel translation.
- Every user-facing string must exist in both languages.
- Arabic copy is NOT a translation of the English — it is written natively.
  English is likewise native, not translationese.
- Use formal Arabic (fusha-adjacent, not colloquial).
- University names: use the official English name and the official Arabic name.
  Do not transliterate.

## What we never do
- Rank universities against each other.
- Use superlatives ("best", "top", "leading") about any single university.
- Invent statistics, quotes, or endorsements.
- Use marketing language ("revolutionary", "game-changing", "unprecedented").
- Use emoji in body copy (nav labels and category icons are acceptable).

## Recurring facts (single-sourced from lib/constants.ts)
- University count: 18 (UNIVERSITIES array length).
- Category count: 7 (CATEGORIES array length).
- Site name: "Universities-Voice" (English) / "صوت الجامعات" (Arabic).
- Copyright holder: "Universities-Voice".

## Formatting
- Dates: Arabic uses Eastern Arabic numerals in production; English uses
  Gregorian. Both use "DD Month YYYY" format.
- Numbers: Arabic text uses Eastern Arabic numerals (٢٠٢٦); English uses
  Western (2026).
